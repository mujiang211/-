# 学生培训课程管理系统
基于 SpringBoot + PostgreSQL 开发的后端管理系统，实现多角色课程管理业务，课程大作业项目。

## ✨ 项目简介
本系统分为三类用户角色：学生、教师、管理员。
- 学生：浏览课程、选课、退课，查看已选课程与截止时间
- 教师：发布、修改、删除自己创建的课程，上传课程大纲文件
- 管理员：管理所有用户，支持学生与教师角色切换，统一权限管控

整体采用三层架构，使用RESTful接口规范，完成数据库建模、身份认证、权限拦截、文件上传等功能。配套软件工程文档：ER图、用例图、软件需求规格说明书SRS。

## 🛠️ 技术栈
- 后端：SpringBoot、Hibernate ORM
- 数据库：PostgreSQL
- 前端：HTML + JavaScript
- 版本管理：Git & GitHub

## 📦 功能清单
1. 用户模块：注册、登录、登出，密码加密存储，禁止重复登录
2. 权限模块：拦截器校验登录状态；教师仅可操作本人发布课程；管理员角色变更
3. 课程模块：课程新增、修改、删除、分页查询
4. 文件模块：课程大纲文件上传、下载
5. 选课模块：学生选课、退课，选课截止时间校验，多对多选课关系维护

## 🗄️ 数据库设计
共设计6张数据表，包含用户表、课程表、选课中间表等；
处理一对多、多对多关联，设置主键、外键、联合唯一约束，防止重复选课。
> 注：课程作业中将学生/教师/管理员分为三张独立用户表；生产环境会优化为单用户表，使用role字段区分角色，减少数据冗余。

## 🚀 本地运行
1. 准备 PostgreSQL 数据库，执行项目内SQL脚本建表
2. 修改 `application.yml` 数据库连接配置（账号密码替换成本地环境）
3. 使用 IDEA 打开项目，启动 SpringBoot 主类
4. 浏览器访问前端页面，注册账号进行功能测试
